# Survivras-tu cette nuit ? Projet html

Jeu narratif interactif en HTML/CSS.


## Concept

Perdu dans une forêt humide, tu trouves une vieille cabane pour passer la nuit. Deux hommes t'y attendent et tu ne peux en garder qu'un :

- Gabin : grand, maigre, un sourire figé et un seul œil qui ne cligne jamais.
- Matias : petit, rond, avec d'énormes oreilles toujours à l'écoute.

Un seul est digne de confiance. 

## Lancer le jeu

1. Télécharge ou clone le projet.
2. Ouvre le fichier index.html dans un navigateur (Chrome, Firefox, Edge...).
3. Clique sur Jouer.
